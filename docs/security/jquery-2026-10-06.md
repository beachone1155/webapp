# jQuery 脆弱性対応（2026-10-06）

## 結論と調査対象

調査開始時の `master` は `adfc8a21f7a82bf9e41fcc837175c14d31248747`（2023-02-11「リポジトリの整理」）。脆弱な依存関係は履歴だけでなく現行コードと GitHub Pages の公開物に残っていた。公開されているという事実は確認したが、攻撃の成立や被害が発生したという意味ではない。

- `smartphonegame/ch5/1-appcahce/jquery-1.7.2.min.js` と `jquery-1.8.2.min.js` が現行ツリーに存在し、両方とも公開 URL で HTTP 200。
- 1.7.2 は `810f39a41e263083b08ccef5e2173ff412919a81`（2020-04-22）で同じ階層に追加されており、2023年の整理後も残存。ルート直下の 404 は、ネストされたファイルがないことの証明にはならない。
- jQuery を読み込む HTML は14件。12件が HTTP の code.jquery.com / 1.8.2、1件が HTTP の Google CDN / 1.6.1、宝箱ゲーム1件が同梱の1.8.2を参照。
- 宝箱ゲームの AppCache は HTML と異なる1.7.2を登録していた。
- Pages は `master` の `/` から公開、独自ドメインなし、HTTPS 強制。調査時の最新ビルドも上記2023年のコミット。既存ブランチは master のみ、タグと Releases はなし。確認した GitHub deployments は github-pages のみ。GitHub 外に手動コピーされた公開物の有無までは確認していない。

調査ログ: https://github.com/beachone1155/webapp/actions/runs/37462365449
履歴調査ログ（後続の文字コード読み取りで失敗する前に履歴は取得済み）: https://github.com/beachone1155/webapp/actions/runs/37462250616

## 対応方針

学習用サンプルを削除・非公開化せず、依存ファイルと参照箇所だけを置換する。archive や警告の dismiss を修正の代わりにはしない。既存の Git 履歴は書き換えない。

全14ページを `smartphonegame/vendor/jquery-3.7.1.min.js` の同一オリジン・相対参照へ統一し、旧版2ファイルを削除。宝箱ゲームのキャッシュ参照も同じファイルへ変更し、リビジョンを `Version.1.001` に更新する。Ajax とエフェクトを維持するため slim 版ではなく通常版を使用する。

3.7.1 は3.x系列の最新版として採用した互換性重視の選択であり、jQuery全体の最新版という意味ではない。2026-10-06確認時、公式配布には4.0.0も存在する。4.x移行に伴うAPI・ブラウザ対応の変更は今回とは分ける。

- 公式配布一覧: https://releases.jquery.com/jquery/
- CVE-2012-6708: https://github.com/advisories/GHSA-2pqj-h3vj-pqgw
- CVE-2015-9251: https://github.com/advisories/GHSA-rmxg-73gg-4p98
- CVE-2019-11358: https://github.com/advisories/GHSA-6c3j-c64m-qhgq
- CVE-2020-11023: https://github.com/advisories/GHSA-jpcq-cgw6-v4j6

これらの公表済み脆弱性の修正を含む版へ更新する。1.12.2への更新だけでは、たとえば3.4.0未満に影響する CVE-2019-11358 は残る。

## 検証

修正前に `scripts/check_jquery.py` が失敗し、修正後に成功することを確認した。

https://github.com/beachone1155/webapp/actions/runs/37463072939

- 静的検査: 旧版参照なし、同梱ライブラリ1本、固定SHA-256一致、14ページの参照と宝箱ゲームの全キャッシュエントリーが解決可能。
- Chrome / agent-browser: 14ページすべてで `jQuery.fn.jquery === '3.7.1'`、重複ロードなし。
- 宝箱ゲーム: 初期画面、当たり、はずれ、再開始。
- Ajaxサンプル: 実際のボタンクリック、ローカルGET、取得したHTMLと画像のDOM反映。
- `$.extend(true, {}, payload)` による Object.prototype 汚染が起きないことを回帰検査。

再実行は `python3 scripts/check_jquery.py`。ブラウザ検証は Node.js 24以上、`agent-browser@0.33.2` と Chromium を用意して `python3 scripts/smoke_jquery.py`。Chromeの自動検出ができない環境では `AGENT_BROWSER_EXECUTABLE_PATH` を指定する。

保持する GitHub Actions ワークフローは読み取り権限のみ。masterへのpushでは、Pagesのビルドコミット、14枚の公開HTML・ライブラリ・キャッシュのバイト一致、旧版2ファイルのHTTP 404も検査する。公開反映の成否は `jQuery security checks` の `verify-pages` ジョブを参照する。

## 確認範囲の限界

Dependabot alerts API は `403 Resource not accessible by integration` で読み取れなかったため、警告 #3 の状態や自動クローズまではAPI確認していない。警告を手動dismissしたり、依存関係の監視を無効化したりしていない。

https://github.com/beachone1155/webapp/security/dependabot/3

歴史的な外部JSONPサービスはブラウザテスト時に接続を遮断している。全サンプルの全操作、古いAppCache対応ブラウザ、既存の文字化け、外部サービスの稼働状況まで修復・保証するものではない。今回の変更前から存在する問題は別途扱う。過去のコミットや外部にコピーされたファイルは、この変更では削除されない。
